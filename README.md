# Linis Co

Custom Astro + React website with Tailwind CSS and GSAP.

## Run locally
Use Node.js >=22.22 (or Node 24 LTS).

```sh
npm install
npm run dev
npm run build
```

Includes eight service pages, seven service-area pages, responsive navigation, gallery filters, accessible FAQs, reduced-motion support, and a React enquiry builder. Enquiries are copied and sent by the visitor via Messenger; there is no server form submission or booking/payment system.

## Content before public launch
Replace illustrative Unsplash photos with approved project photographs and before/after pairs. Add verified testimonials with permission. Confirm service inclusions, pricing, privacy wording, and contact-channel preference with the owner. No reviews, prices, or project results have been invented.
